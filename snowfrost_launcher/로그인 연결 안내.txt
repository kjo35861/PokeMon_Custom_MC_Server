포켓메이트 0.3.1 · Prism 연결 안내

이 버전은 설치된 Prism Launcher에 게임 실행을 요청합니다.
Microsoft API 키, Client ID, 앱 등록이나 유료 인증 서비스는 필요 없습니다.

1. Prism Launcher를 설치합니다.
https://prismlauncher.org/download/

2. Prism에서 본인 Microsoft 계정으로 로그인합니다.
Minecraft Java 이용 권한이 있는 계정이 필요합니다.
포켓메이트에 비밀번호·인증 코드·토큰을 입력하지 않습니다.

3. Prism에서 순정 Minecraft 1.21.1 인스턴스를 만들고 한 번 실행합니다.

4. 포켓메이트를 실행하고 게임 시작을 누릅니다.
일반 설치는 자동으로 찾습니다. Prism을 직접 먼저 켤 필요는 없습니다.

자동으로 찾지 못하면 톱니바퀴에서 Prism 실행 파일, 데이터 폴더, 인스턴스 ID를 지정합니다.
인스턴스 ID는 화면 표시 이름이 아닌 실제 인스턴스 폴더 이름입니다.

서버 업데이트 주소가 없으면 순정 1.21.1을 시작합니다.
서버 주소를 지정하면 별도 Prism 서버 인스턴스를 만들고 업데이트를 적용합니다.
원본 순정 인스턴스에는 서버 모드를 적용하지 않습니다.

로그인 만료나 오류가 발생하면 Prism 화면에서 해결해주세요.
Java 21·메모리·Prism 창 표시 설정도 Prism에서 관리합니다.
포켓메이트는 Prism의 accounts.json이나 저장 토큰을 읽지 않습니다.
