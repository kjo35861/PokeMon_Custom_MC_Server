포켓메이트 메뉴 0.20.0 · Minecraft 1.21.1 / Fabric

구성
- WebGUI 2.0.0 및 pocketmate-estates-0.12.0.jar가 필요합니다.
- pocketmate-webgui-alpha-0.1.0.jar는 클라이언트 반투명 합성 보완용입니다.
- 같은 pocketmate-estates 모드의 이전 버전 JAR을 함께 넣지 마세요.
- 계정/서버 비밀키/실제 월드와 재화 파일은 배포 ZIP에 포함하지 않습니다.

적용
이번0.20.0은 상점 서버 코드가 추가되어 게임을 완전히 종료한 상태에서 모드를 교체한 뒤 다시 실행해야 합니다. /webgui reload만으로 새 거래 기능이 생기지 않습니다.
웹 HTML/CSS/JS만 수정한 경우에는 /webgui reload 후 메뉴를 다시 열면 됩니다. 메뉴 키는 해당 인스턴스의 WebGUI 키 설정을 사용하고 Esc 또는 닫기 버튼으로 돌아갑니다.

상점
구매/판매, 한글 이름과ID 검색, 24개씩 페이지, 수량/합계 확인을 제공합니다.
바닐라: 건축블럭 / 색깔블럭 / 장식블럭 / 광물 / 농작물.
포켓몬: 몬스터볼 / 지니는 물건 / Z크리스탈 / 메가나이트. 아직 상품은 없습니다.
기본 구매가100원 / 판매가50원. 판매는 광물과 농작물/파종재료만 가능합니다.
구매용 농작물은 씨앗과 실제 심을 수 있는 재료이며, 판매에는 수확물도 포함됩니다.
금액은 영지 금고와 같은 포켓메이트 개인 지갑에서 처리합니다. 테스트 재화를 자동 지급하지 않습니다.
이름/인챈트 등 추가 정보가 있는 아이템과 장비/보조손 슬롯은 판매하지 않습니다.

가격
첫 월드 시작 시 config/pocketmate-shop.json이 생성됩니다.
현재 randomEnabled=false로 고정 가격입니다. 추후 아이템별 기준가, 판매 가격 주기/편차를 설정할 수 있습니다. 설정 변경 뒤에는 월드/서버 재시작이 필요합니다.

검증 범위
코드/레지스트리/임시 저장소 및 모의 브라우저 검사를 통과했습니다. 실제 게임 거래와 아이콘 표시는 사용자 확인 대기입니다. 게임 텍스처는 해당 클라이언트의 설치된 리소스에서 읽습니다.
자세한 규칙과 전체 상품 목록은 저장소의 docs/SHOP.md 및 docs/shop-catalog.csv를 확인하세요.
