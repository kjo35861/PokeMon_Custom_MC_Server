# 포켓메이트 메가스톤 등록 ID

포켓메이트 메가진화 0.1.4는 커스텀 메가스톤의 아이템 등록 이름을 `pocketmate_mega:mega_stone_N`으로 바꾼다. EeveeMega 1.1.0의 프레임워크 모드 ID는 호환 의존성에 사용한다. 모델과 번역을 새 이름으로 제공하고, 생성된 종 데이터와 메가스톤 목록도 같은 ID를 참조한다.

등록 시 NeoForge의 별칭으로 이전 128개 메가스톤 이름을 새 이름에 연결한다. 서버의 상점 설정과 즐겨찾기 파일은 백업 후 별도로 옮긴다. 배포 시 클라이언트와 서버에 같은 버전의 호환 모드를 적용해야 한다.

빌드에는 기존 EeveeMega 프레임워크 JAR, Pixelmon 9.4.3 JAR, 모델과 종 데이터가 포함된 생성 리소스 폴더가 필요하다. `tools/build_eeveemega_bridge.py`가 빌드용 복사본에서 메가스톤 참조를 변환한다.

버전 0.1.5는 이전 리소스팩의 원본 메가스톤 모델과 아이콘을 54~58번 슬롯에 복원한다. 빌드 시 `--recovered-pack`에 해당 리소스팩 ZIP을 지정한다.
