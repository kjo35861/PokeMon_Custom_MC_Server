# 전설·환상 포켓몬 칭호

최종 v10 디자인 94종을 모드 0.10.0에 등록했다. 기존 소유권·착용 저장 형식을 유지하며 자동 기본 지급하지 않는다. 채팅은 개별 PNG 글리프와 칭호 색을 사용하고, 프로필 편집 목록·카드는 같은 아이콘을 표시한다.

## 적용

클라이언트와 서버 모두 0.10.0 JAR로 교체하고 게임/서버를 재시작해야 한다. `/webgui reload`만으로 Java 칭호 등록과 채팅 폰트를 갱신할 수 없다. 아이콘 폰트는 클라이언트 모드에 포함되어 별도 리소스팩 선택이 필요 없다.

## 지급

모든 등록 칭호 일괄 지급(OP 필요): `/pmprofile grantall @s title`. 다른 유저에게는 `@s` 대신 닉네임을 입력한다. 기존 기본 칭호와 94종을 모두 포함하며, 중복 지급하지 않고 장착 상태도 바꾸지 않는다. 모드 0.10.1에서 지원한다.

관리자: `/pmprofile grant <플레이어> title legendary_384` (레쿠쟈). 지급 후 프로필 편집을 다시 열어 장착한다. 닉네임 처리와 권한·보유 여부 검사는 기존 시스템을 따른다. 이번 변경은 등록·관리자 지급·착용·표시 연결이며 최초 포획 이벤트 자동 지급은 아직 구현하지 않았다.

## 획득 조건 표시 (0.10.2)

보유 칭호 목록의 각 카드에 획득 조건을 표시한다. 전설·환상 94종은 해당 포켓몬 서버 최초 포획으로 표기하며, 자동 지급 미연결 및 현재 관리자 지급 상태를 목록 상단에서 안내한다. 기본/해제/관리자 지급 칭호는 각각의 실제 지급 방식으로 구분한다. 서버 카탈로그 필드가 추가되어 모드 재시작이 필요하다.
