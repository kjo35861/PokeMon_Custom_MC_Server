# Pixelmon 서버 이벤트 연동

Minecraft 1.21.1, NeoForge, Pixelmon 9.4.3 기준. 기존의 야생 전투, 포획, 경험치·레벨 임무 및 도감 번호로 연결된 종별 최초 포획 칭호에 서버 이벤트를 연결했다. 자연 스폰 표시가 기록된 개체만 전투·포획으로 인정한다. 배포 전 이미 월드에 있던 미표시 개체와 과거 포획에는 소급하지 않는다.

포획 이벤트가 취소되지 않고 실제 포획자 저장소에 등록된 후에만 집계한다. 최초 포획 당첨자와 칭호 소유권은 서버 프로필 파일에서 한 번에 저장한다. PvP와 포획 종료는 배틀 승리로 처리하지 않는다. 포켓몬 상점은 운영자가 등록하기 전에는 비어 있다.

NeoForge 빌드, 프로필 재시작 후 최초 수령자 유지 검사, JS 구문을 확인했다. 서버를 종료한 뒤 JAR과 profile.js 배치 예약. 서버 재시작 후 새 자연 스폰을 대상으로 실제 포획·배틀·육성 집계와 칭호 지급을 확인해야 한다.
