# 관리자 상점 순서 변경과 별도 알림

2026-11-25, Pocketmate Estates 0.15.5 / 웹 메뉴 v0.24.0. 서버와 현재 Pixelmon 테스트 인스턴스에 파일을 배치했다. 실제 게임 화면과 서버 운영 데이터에서의 확인은 사용자 확인 대기다.

## 안내 문구

관리자·상점·임무·영지 화면의 임시 작업 안내를 본문에서 제거하고 화면 오른쪽 아래의 고정 알림으로 분리했다. 알림은 본문 높이에 영향을 주지 않아 성공/오류 문구가 생겨도 검색창과 목록을 밀지 않는다.

- 일반 안내는 4.5초, 오류는 8초 뒤 닫힌다. × 버튼으로 먼저 닫을 수 있다.
- 메뉴 조작을 막거나 키보드 포커스를 강제로 옮기지 않는다.
- 관리자 목록을 다시 그릴 때 스크롤 위치를 유지한다.
- 입력창의 유효성 설명이나 상점 점검 상태 등 지속적인 기능 정보와 임시 작업 알림은 구분한다.

## 품목 순서

관리자 → 상점 목록의 **순서 ↑ / ↓** 버튼으로 현재 목록에서 인접한 품목의 앞이나 뒤로 이동한다. 검색·분류·거래 상태 필터가 있으면 그 목록의 이웃을 기준으로 이동한다. 첫/마지막 품목은 해당 방향 버튼이 비활성화된다. 페이지 경계의 이웃도 이동할 수 있다.

순서는 서버의 기존 상점 설정에 `order` 목록으로 저장된다. 구매·판매·즐겨찾기 목록은 같은 서버 순서를 필터링해서 표시한다. 재접속/서버 재시작과 가격 수정·일시정지 후에도 순서를 유지한다. 삭제한 품목을 재등록하면 남겨 둔 위치 정보를 사용하며, 순서에 아직 없는 새 품목은 기존 순서 뒤에 ID순으로 추가된다.

기존 설정에 `order`가 없으면 기존 ID순으로 동작한다. 기존 가격·판매 허용·점검 상태·삭제 정보는 보존한다. 순서 저장도 OP2 권한과 revision을 확인하고 임시 파일을 통한 원자적 저장 및 직전 파일 백업을 사용한다. 다른 관리자의 변경 이후 요청, 존재하지 않는 품목/이웃과 잘못된 방향은 저장하지 않는다. 순서 변경이 설정 revision을 바꾸므로 이전 거래 견적은 새로 확인하게 된다. 인벤토리나 재화는 순서 변경으로 수정하지 않는다.

## 검증

- Fabric 빌드 및 JUnit 115개, NeoForge 빌드 및 JUnit 88개 통과. NeoForge 일반 JUnit에서 부트스트랩할 수 없는 기존 레지스트리 테스트 제외 설정은 유지했으며, 순서 저장/마이그레이션/권한/revision/저장 실패 검사는 Fabric 테스트에서 실행했다.
- Headless 모의 화면: 순서 변경, 페이지 경계 이동, 필터 경계, 오류 시 순서 유지, 성공/오류 알림 전후 목록의 Y좌표 불변, 알림 닫기/시간 만료, 다크·라이트 및 화면 크기 4종 확인.
- 기존 관리자 권한·편집, 연속 상점 거래, 임무, 영지 커뮤니티 모의 테스트도 통과했다. 이번 재검사의 출력은 별도 `notifications-v024` 폴더에 저장해 기존 자료를 덮어쓰지 않았다.
- 다크/라이트 모의 스크린샷을 육안 확인했다. 공개 자료는 `docs/evidence/`의 v0.24 이름으로 별도 보관한다.
- 서버와 클라이언트의 새 JAR 해시 및 웹 배포 목록 262개 일치, JAR/배포 ZIP CRC, 실제 런처의 CheckLocal/VerifyApprovedContent 검사 통과.
- 게임·Prism·서버는 실행하거나 종료하지 않았다. 실제 게임 내 WebGUI 동작, 실제 관리자 저장과 재접속 확인을 완료한 것으로 표기하지 않는다.

## 배치와 적용

Pocketmate Estates NeoForge 0.15.5를 서버와 `Pocketmate-PIXELMON-NeoForge` 인스턴스에 설치했다. 각 위치의 이전 0.15.4 JAR와 변경 웹 파일은 저장소 밖 `%LOCALAPPDATA%/PocketmateServerBackups/2026-11-25-admin-order-notification-0155`에 보관했다. 상점 운영 설정 파일과 계정·개인 재화·월드 본문은 변경하지 않았다. 로컬 런처의 승인 목록과 배포 사본도 새 JAR로 갱신했다.

웹 변경은 index/admin/shop/missions/estate-app 및 새 notifications JS/CSS에 적용했다. 기존 appearance.css/profile.css 변경은 수정하지 않았다. 배포본은 Downloads의 `pocketmate-menu-admin-order-2026-11-25/PocketmateMenu-NeoForge-v0.24.0.zip`이며 WebGUI 2.0.0은 별도로 필요하다.

Java 코드가 바뀌었으므로 다음 서버와 게임 시작부터 적용된다. `/webgui reload`만으로 새 순서 저장 기능을 적용할 수는 없다. 작업 중 대상 게임/서버 프로세스가 없는 것을 확인한 뒤 파일을 교체했다.

이때 이전 메가 크기 수정의 서버 대기 큐도 실제 적용해 메가 보완 모드 0.1.3 파일 배치를 완료했다. 이전의 '교체 대기' 검증 자료는 당시 기록으로 보존하며 서버 시작/실제 크기 렌더링을 새로 검증한 것으로 바꾸지 않았다.
