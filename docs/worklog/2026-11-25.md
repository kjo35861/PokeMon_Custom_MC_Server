
## 다크라이·레쿠쟈 10차 디자인 수정

- 다크라이의 달을 악몽의 장막과 눈으로 교체해 루나아라와 구분. 레쿠쟈는 용의 비늘·지느러미와 구름으로 재설계.
- 칭호·색 유지, 다른 92종 PNG 동일 확인. 94종 PNG·아틀라스·폰트 매핑 정적 검사 통과 및 비교 시트 육안 확인.
- 게임 미적용·미검증. 사용자 디자인 확인 대기이므로 README 완료 항목에 반영하지 않음.

## 최종 94종 칭호 등록

- 사용자가 최신 전체 시안을 확인한 뒤 마인크래프트 추가를 요청하여 디자인 채택. 실제 게임 표시 검증과는 구분한다.
- 모드 0.10.0: 전설 71종·환상 23종을 `legendary_<도감번호>`로 기존 서버 소유권 카탈로그에 추가. 기존 저장 형식과 기본 지급 항목 유지. 각 칭호는 관리자 지급 후에만 착용 가능.
- 채팅에 개별 글리프·원본 칭호색 표시. PNG 자체색 보존을 위해 글리프는 흰색 틴트. 클라이언트 JAR 안에 최종 v10 아틀라스·비트맵 폰트 포함.
- 프로필 목록·카드·미리보기에 동일 아이콘·색 연결. 밝은 테마 목록은 대비용 색·이미지 사용, 어두운 프로필 카드는 원본색 유지.
- Java 테스트 67개 실패 0, 빌드 통과. 94종에 대해 미보유 장착 거부·지급·착용·재로드 유지 검사. 설치 JAR 아틀라스와 최종 디자인 동일 확인.
- Java 실행 프로세스가 없는 것을 확인한 후 테스트 인스턴스의 이전 JAR와 변경 웹 파일을 비공개 백업하고 0.10.0 및 웹 자산 설치. 설치 파일 바이트 일치 확인. 메뉴 0.15.0 패키지 생성.
- 게임 실행·조작·실제 채팅 검증은 하지 않음. Java 모드와 폰트가 바뀌므로 게임 재시작 필요. 최초 포획 자동 지급 이벤트는 이번 등록 변경에 포함되지 않음.
- 사용법·전체 지급 ID: docs/LEGENDARY_TITLES.md. 게임 확인 대기이므로 구현 완료 항목은 README에 반영 보류.

## 마인크래프트 기본 글꼴 고운돋움

- 사용자 지정 Google Fonts Gowun Dodum Regular의 원본 TTF·OFL 1.1 전문을 확보하고 출처·SHA-256 기록. 원본 폰트는 수정하지 않음.
- 모드 0.10.3에서 기본 게임 글꼴을 TTF 공급자로 연결. 공백과 미지원 문자는 바닐라 공급자로 보완하고 기존 칭호 아이콘용 두 비트맵 폰트는 유지. 웹 메뉴 폰트 변경과는 별개.
- 한글 완성형 11,172자·영문·숫자 지원, fallback과 아이콘 폰트 분리, JAR 리소스 바이트 일치 검사 통과. Java 68개 테스트 및 빌드 통과. 시각·게임 검증은 하지 않음.
- 이전 0.10.2 교체 대기 도우미만 종료하고 이전 pending 빌드를 비공개 백업하여 버전 역행 방지. Java 프로세스가 없는 상태에서 이전 모드 백업 후 0.10.3 설치, 해시 일치 확인. 게임은 실행·종료하지 않음.
- 적용은 게임 재시작 필요. 최종 게임 표시 사용자 확인 전까지 README 완료 항목 반영 보류.

## 고운돋움 기본 글꼴 로딩 실패 수정

- 사용자가 Mojang 로딩 화면 정지를 보고. 테스트 인스턴스 로그를 읽어 0.10.3의 `FileNotFoundException: pocketmate:font/font/gowun_dodum.ttf`와 `Default font failed to load` 확인. 원인은 에이전트의 TTF file 경로 중복. 기존 정적 검사로 게임 작동을 입증하지 못했음을 명시하며 글꼴 적용은 수정·확인 중.
- 0.10.4에서 file을 `pocketmate:gowun_dodum.ttf`로 수정. TTF 로더가 font/를 붙이는 경로 해석 검사를 추가. 대문자 라이선스 리소스도 소문자로 변경하여 잘못된 리소스 경로 경고 방지.
- 빌드·Java 68개 테스트 통과. 한글 11,172자·영문·숫자·fallback·아이콘 분리·실제 로딩 경로·소문자 경로·JAR 리소스 일치 검사 통과. 게임 재실행 검증은 아직 하지 않음.
- 수정 JAR를 pending으로 준비하고 게임 종료 후 설치 도우미를 숨김 실행. 게임 강제 종료·실행·화면 조작은 하지 않음. 사용자에게 종료 후 10초 대기·재실행 안내. README 완료 반영 보류.
