- PixelmonMissionSignals 계약을 자연 출처 확인 야생만 허용하도록 강화. 소유·명령어·스포너·레이드·출처 불명·PvP·포획 종료 제외. 같은 포켓몬 재처치·배틀 재전달은 중복 계산하지 않음. 실제 Pixelmon 이벤트 구독은 여전히 NeoForge 이식 대기이며 활성화했다고 표기하지 않음.
- 임무 유형 중복 방지와 전설/색이 다른 포켓몬 등 운 의존 목표 제외를 유지. 화면에 잔여 무료 교체 횟수, 확인창, 취소, ? 운영 규칙 안내 추가. 브라우저의 교체 요청에는 임무 ID·날짜만 포함하고 서버가 배정과 권한을 결정.
- 검증 과정에서 고정 시각 05:59:59를 1초 전진해 의도하지 않게 06시를 넘긴 새 검사 2개가 실패. 같은 날짜 교체 검사는 1ms 전진으로 고치고 별도의 06시 경계 검사를 유지해 최종 전체 87개(임무 19개) 실패 0, 빌드 통과.
- 모의 브라우저에서 확인 취소 시 요청 없음·동일 슬롯 교체·횟수 0·재조회 유지·완료/최종 수령·날짜 경계·라이트/다크/160% 글자·규칙 도움말 검사 통과. 이전 0.16.0 모의 화면과 보고서를 보존하고 0.16.1 규칙 화면을 별도 증거명으로 저장. 실제 게임·Pixelmon 검증은 하지 않음.
- Java 프로세스가 없는 상태에서 이전 JAR·웹 자산을 비공개 백업 후 테스트 인스턴스에 0.11.1 설치, 바이트/해시 일치 확인. 게임 실행·종료·화면 조작은 하지 않음. 재시작 필요. 사용자 확인 전이므로 README 완료 항목은 갱신하지 않음.

## 싱글 월드 진입 시 임무 통계 조회 충돌 수정

- 사용자가 싱글 월드 진입 종료와 추가 오류 로그를 제공. 첨부 자료는 시스템 정보이며, 로컬 latest.log와 실제 crash-2026-11-25_01.52.57-server.txt를 읽어 `MissionsMod.custom -> sample -> END_SERVER_TICK`의 NPE를 확인. 같은 오류가 START_SERVER_TICK의 초기 배정에서도 반복됨. 실제 월드가 종료된 오류이므로 임무 기능은 수정·게임 확인 중으로 유지.
- 원인은 새 Identifier를 custom-stat 레지스트리 값으로 사용한 에이전트 코드. 0.11.2에서는 Stats 등록 상수 사용 및 레지스트리 키로 실제 등록 객체를 해석한 뒤 조회. 미등록/null 통계는 0. 모든 이동 통계도 같은 경로로 처리.
- 집계 예외를 플레이어별로 격리하고 30초 재시도/로그 제한. 실패 시 누적 통계 기준을 제거해 나중에 과거 행동을 소급하지 않음. 기준을 확인하지 못한 무료 교체는 차감하지 않으며 정상 교체는 직전 표본 기준을 재사용. 임무 자료 형식/진행도/수령/교체·영지·프로필·월드 파일을 변경하지 않음.
- 회귀 검사 확장: 일반 JUnit의 레지스트리 초기화 시 Minecraft 런타임 변환 부재로 IllegalAccessError 발생. Fabric 공식 unit-testing 문서에 따라 fabric-loader-junit 추가 후 테스트 전용 WebGUI 의존성도 제공해 해결. WebGUI의 Java-25 Gradle 메타데이터는 @jar 지정으로 우회하며 테스트에서만 사용. 실제 모드/네이티브 브라우저를 시작한 것은 아님.
- 최종 전체 90개 테스트 실패 0 및 빌드 통과. 신규 레지스트리 검사 3개에서 실제 바닐라 등록 상수·동일 값 신규 식별자·미등록/null·이동 거리 long 합계 확인. 게임/서버/월드를 실행하지 않은 단위 검사로 실제 재진입 검증과 구분.
- 수정 0.11.2 JAR를 기존 JAR 비공개 백업 후 테스트 인스턴스에 설치, 파일 해시 일치 확인. 메뉴 패키지 0.16.2. 게임 실행/종료·UI 조작·월드 자료 수정은 하지 않음. 사용자가 게임 재실행하여 확인해야 함. README 완료 항목 갱신 보류.
- 공개 증거는 원인 요약과 검사 결과만 포함. 실제 충돌 보고서의 계정/월드/시스템 정보는 게시하지 않음. 테스트 참고: https://docs.fabricmc.net/develop/automatic-testing
