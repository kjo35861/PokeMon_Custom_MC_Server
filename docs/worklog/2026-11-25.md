## 싱글 월드 진입 시 임무 통계 조회 충돌 수정

- 사용자가 싱글 월드 진입 종료와 추가 오류 로그를 제공. 첨부 자료는 시스템 정보이며, 로컬 latest.log와 실제 crash-2026-11-25_01.52.57-server.txt를 읽어 `MissionsMod.custom -> sample -> END_SERVER_TICK`의 NPE를 확인. 같은 오류가 START_SERVER_TICK의 초기 배정에서도 반복됨. 실제 월드가 종료된 오류이므로 임무 기능은 수정·게임 확인 중으로 유지.
- 원인은 새 Identifier를 custom-stat 레지스트리 값으로 사용한 에이전트 코드. 0.11.2에서는 Stats 등록 상수 사용 및 레지스트리 키로 실제 등록 객체를 해석한 뒤 조회. 미등록/null 통계는 0. 모든 이동 통계도 같은 경로로 처리.
- 집계 예외를 플레이어별로 격리하고 30초 재시도/로그 제한. 실패 시 누적 통계 기준을 제거해 나중에 과거 행동을 소급하지 않음. 기준을 확인하지 못한 무료 교체는 차감하지 않으며 정상 교체는 직전 표본 기준을 재사용. 임무 자료 형식/진행도/수령/교체·영지·프로필·월드 파일을 변경하지 않음.
- 회귀 검사 확장: 일반 JUnit의 레지스트리 초기화 시 Minecraft 런타임 변환 부재로 IllegalAccessError 발생. Fabric 공식 unit-testing 문서에 따라 fabric-loader-junit 추가 후 테스트 전용 WebGUI 의존성도 제공해 해결. WebGUI의 Java-25 Gradle 메타데이터는 @jar 지정으로 우회하며 테스트에서만 사용. 실제 모드/네이티브 브라우저를 시작한 것은 아님.
- 최종 전체 90개 테스트 실패 0 및 빌드 통과. 신규 레지스트리 검사 3개에서 실제 바닐라 등록 상수·동일 값 신규 식별자·미등록/null·이동 거리 long 합계 확인. 게임/서버/월드를 실행하지 않은 단위 검사로 실제 재진입 검증과 구분.
- 수정 0.11.2 JAR를 기존 JAR 비공개 백업 후 테스트 인스턴스에 설치, 파일 해시 일치 확인. 메뉴 패키지 0.16.2. 게임 실행/종료·UI 조작·월드 자료 수정은 하지 않음. 사용자가 게임 재실행하여 확인해야 함. README 완료 항목 갱신 보류.

## EeveeOnline 서버 리소스팩 캐시 확인·복구

- 사용자 지정 인스턴스의 resourcepacks는 비어 있고 로컬 월드 datapacks도 비어 있음. 월드 본문/플레이어 데이터는 읽지 않음. server-resource-packs에는 캐시 3개 존재. options 선택 ID와 최근 로그가 가리키는 캐시 1dda7321ec9af73720faa269035d23a5d2985961을 확인.
- 해당 캐시의 assets/eeveemega 93개와 Pixelmon 메가 모델 91개(경로 기준 42종/43폼) 확인. data/ 엔트리는 없어 서버 종족/폼 데이터팩 확보로 표기하지 않음.
- 원본 ZIP 헤더의 파일명/해제 크기/CRC가 변형되어 일반 읽기 오류 발생. 원본을 보존하고 안전한 중앙 경로·실제 DEFLATE 스트림으로 Downloads/eevee-resourcepack-recovered-2026-11-25에 표준 ZIP 재작성. 5,445개 전체 읽기/CRC 통과, 입력 SHA-1은 캐시명과 일치, 파일별 해시 manifest 저장. 상세 해시/한계는 docs/EEVEE_RESOURCEPACK_RECOVERY.md.
- 원본·복구 팩·개별 자산·전체 접속 로그는 저장소에 넣지 않음. 게임/서버/Prism 실행·종료·화면 조작·온라인 추가 다운로드·실제 팩 설치 없음. 외형 렌더링·배틀/폼 매핑은 미검증, README 적용 완료 표기 없음. 문서/별도 복구 파일만 생성하여 재시작 불필요.

## EeveeMega 기능별 코드 재확인

- 사용자 후속 질문으로 9개 특성, 오거폰 소지 가면 폼 전환, 덩굴방망이 타입/표시, 진단/지급 명령어를 기존 javap 결과에서 재확인. docs/EEVEEMEGA_DEPENDENCIES.md에 기능별 근거 추가.
- 테라셀은 번역의 단순 데미지 반감과 달리 타입 상성을 최대0.5배로 보정하는 코드. 테라클러스터는 노말/특수/위력120 기본 JSON과 빈 effects만 있어 폼별 특수효과 전체 구현으로 안내하지 않음. 128개 스톤 자리와 실제 메가 종족 수를 구분.
- 정적 코드 검토만 수행, 게임/서버/Prism 실행이나 실제 배틀 검증 없음. 문서만 변경하여 재시작 불필요.


- Prism의 최신 로딩 오류는 Sodium 0.8.14 beta 및 동봉 API가 NeoForge 21.1.262 이상을 요구해 발생. 대상 JVM이 실행 중이므로 테스트 인스턴스 종료 후 Sodium과 Iris만 별도 백업으로 이동하도록 예약. 재실행 검증 대기.


- Xaero 미니맵이 월드맵 1.44.0 이상을 요구하는 충돌 확인. Prism에서 1.47.0으로 변경된 상태와 셰이더 초기화까지 로그 확인. 공식 SHA-512가 일치하는 1.47.0으로 런처 설치 목록도 통일. 실제 영지 지도 확인 대기.
