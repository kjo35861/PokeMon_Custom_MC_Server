## 클라이언트 게임 창 전경 활성화

- 게임 실행 시 마인크래프트 창을 앞으로 가져오라는 요청을 구현했다. `GameWindowActivation.cs`를 추가해 실행 PID와 Minecraft/GLFW 창 식별 후 활성화하고, 기존 런처 최소화 처리를 그 뒤로 옮겼다. 지연 생성·최소화 복원·창 교체·게임 종료·취소·Windows 활성화 거절을 처리한다. 항상 위 설정은 사용하지 않는다.
- .NET Framework 클라이언트 빌드 성공. 백엔드 검사 60개 통과(기존 53개와 모의 창 활성화 7개). 실제 게임·Prism·서버를 실행/종료하거나 실제 게임 창을 조작하지 않았다.
- 기존 배포 EXE·ZIP과 현재 클라이언트 폴더의 별도 Foreground EXE에 수정본을 배치하고 이전 파일은 로컬에 백업했다. 새 EXE SHA-256은 `abdd192e576ddc95c90e95fcf235318c5b873e76aaa3883eddf9524d0625b999`이다. 기존 클라이언트 설정·팩 목록은 변경하지 않았다.
- 실행 중인 원래 클라이언트 EXE는 잠겨 있어 종료 후 자동 교체하도록 숨김 도우미를 대기시켰다. 프로세스 종료 없이 파일 교체만 수행한다. 임시 파일 잠금·백업·반복 적용·예상하지 않은 해시 거부 등 업데이트 도우미 검사 5개도 통과했다.
- 클라이언트 재실행 필요. 실제 게임 전경 전환은 사용자 확인 대기이며 README 검증 완료 반영은 보류한다. 상세 내용과 공식 API 출처는 `docs/LAUNCHER_GAME_FOREGROUND.md`에 기록했다.


- 상점 아이콘 렌더 처리량과 캐시 전송 최적화, 기존 이미지 DOM 유지. NeoForge 빌드 및 설치 확인. NeoForge 테스트 서버 목록을 백업 후 포켓메이트 단일 항목으로 교체. 실제 화면과 성능 확인 대기.

## Xaero 포켓몬 레이더 아이콘

- 기존 인스턴스는 미니맵 아이콘 항상 표시 및 월드맵 미니맵 레이더 표시가 켜져 있었지만 Pixelmon 전용 아이콘 팩이 없었다. Xaero의 모델 기반 아이콘 생성은 모드 모델 지원을 보장하지 않는다.
- Pixelmon 9.4.3의 텍스처 ID 3,394개를 스프라이트로 연결하고, 매칭되지 않는 변종에는 몬스터볼을 기본 아이콘으로 지정했다. 배포 팩에 리소스팩과 Xaero 미니맵 기본 레이더 프로필을 추가했다.
- 리소스팩 ZIP 및 참조 검사, 런처 빌드, 백엔드 검사 60개를 통과했다. 게임 내 표시는 사용자 확인 대기 상태다. 서버 재시작 없이 클라이언트에 적용한다. 현재 실행 중인 인스턴스에는 리소스팩 파일을 추가했으며 게임 내에서 켜서 바로 확인할 수 있다.

## Accessories 업데이트 팩 버전 오류

- 버튼 패치 배포 시 버전 접미사가 누적되어 115자가 되면서 런처의 100자 제한에 걸렸다. 설치본과 배포용 팩에 52자 버전을 적용했고 패치 JAR의 해시와 크기를 확인했다.
- 설치 파일 빌드 단계에 팩 버전 길이 검사를 추가하고 101자 입력이 거부되는 것을 확인했다. 실제 게임 실행은 사용자 확인 대기 중이다.

## Xaero 포켓몬 스프라이트 식별 수정

- 실제 게임에서 몬스터볼만 표시된다고 보고받았다. Pixelmon 렌더러는 Xaero 기본 조회에 공통 빈 텍스처를 반환한다. Xaero의 변종 확장 지점에 Pixelmon 엔티티의 팔레트 스프라이트 ID를 반환하는 메서드를 연결했다.
- 6,875개 스프라이트 및 텍스처 ID의 파일 참조, NeoForge 빌드 및 테스트, 배포 JAR의 두 클래스와 매니페스트 해시를 검사했다. 현재 런처와 설치본을 갱신했고 실제 지도 표시는 확인 대기다. 클라이언트 재실행이 필요하다.

## 런처 폴더 이름과 GitHub 설치 마법사

- 런처 소스와 빌드 경로를 pocketmate_launcher로 이동하고 관련 문서·공개 검사 경로를 갱신했다. 이전 공개 증거 링크 경로는 유지했다.
- 새 경로에서 런처 빌드와 백엔드 검사 60개를 통과했다. 최신 Windows 설치 마법사를 GitHub Release launcher-1.21.1-2026-11-26에 게시하고 업로드 크기와 해시를 확인했다. 이후 클라이언트 변경 시 새 Release를 수동 게시하는 방식을 문서에 기록했다.

## 상점 등록 허용 상태 동기화

- 관리자 등록 가능 품목에서 확인창을 거쳐 전체 등록부를 상점 목록과 비교한다. 미등록·구매와 판매 모두 꺼짐 품목은 비허용으로 저장하고, 후자는 상점에서도 삭제한다. 한 쪽이라도 활성 상태면 유지한다.
- 무권한·이전 버전 거부, 단일 저장, 재동기화 무변경, 거래 상태 경계 사례 테스트 통과. NeoForge 빌드와 JavaScript 검사도 통과했다. 다음 run.bat 실행에 서버 패치 적용 예약, 인게임 확인 대기.

## 메뉴 스크롤·Pixelmon 기믹도구·테라스탈 안내

- 상점과 관리자 페이지의 스크롤 영역 노드를 재사용하고, 상점의 주기 조회에서 잔액만 바뀌면 전체 목록을 다시 그리지 않도록 했다.
- 기믹도구 탭에 Pixelmon Z링·키스톤과 계정당 한 번 구매하는 테라스탈오브 해금을 추가했다. 기존 비허용 설정에 있던 해당 상품만 서버 시작 때 해제한다. 모드 품목은 관리자 검색에서 등록 ID로 추가 가능하다.
- Pixelmon 9.4.3의 테라스탈 조각 부족 메시지를 한국어 클라이언트에서 포켓몬 이름, 필요 수량 순으로 출력하게 했다. NeoForge 빌드, Fabric 테스트, JS 구문, 브라우저 모의 상점 테스트를 통과했다. 서버 패치는 다음 run.bat 실행에 적용되며 인게임 검증은 대기 중이다.

## 기존 상점 품목 정렬 및 판매 분류

- 다음 서버 시작에 실제 등록 목록을 한 번만 분류·블록 종류 순으로 정렬하도록 예약했다. 정렬은 순서만 저장하며 기존 등록·삭제·비허용 및 가격과 구매·판매 상태는 건드리지 않는다.
- 일반 등록 품목의 구매·판매를 각각 설정할 수 있게 하고, 선택한 분류의 판매 품목 유무를 서버가 전달하도록 했다. 테라스탈오브는 계정 해금 상품이므로 구매 전용이다.
- 목록·가격 보존 자동 테스트, NeoForge 빌드, 판매 탭 활성과 잠금의 브라우저 모의 검증 통과. 실제 서버 정렬 및 화면 확인은 재시작 후 대기.

## 기믹도구 계정 해금

- Z링·메가링·테라스탈오브 구매를 Pixelmon의 계정 해금으로 처리한다. Z기술과 메가진화는 Pixelmon 9.4.3의 공통 Mega 권한을 쓰므로 둘 중 하나를 해금하면 두 상품의 중복 결제를 막는다. 테라스탈은 별도 권한이다.
- 관련 설정 및 권한 매핑 테스트, NeoForge 빌드, 모의 상점 검사를 통과했다. 다음 run.bat 시 서버 패치 적용을 예약했다. 실제 구매와 Pixelmon 전투 동작은 확인 대기다.

## Pixelmon 상점 품목 검색

- 전용 서버의 등록 비허용 목록에 Pixelmon 품목 2,149개가 있어 기존 품목 추가 검색에서 숨겨졌음을 확인했다. 비허용 품목도 검색 결과에 표시하고 선택 시 허용 관리로 연결한다. 서버 규칙 제한과 수동으로 저장한 비허용 상태를 유지한다.
- Pixelmon 한국어 이름을 모드 리소스에서 읽고 이름·아이템 ID의 정확히 일치하는 결과를 우선했다. NeoForge 빌드, Fabric 테스트, 관리자 브라우저 모의 검증을 통과했다. 다음 run.bat 실행에 적용되며 인게임 실제 한글 검색 확인은 대기 중이다.

## 포켓몬 상점 초기 목록과 몬스터볼 변종

- 메가링·Z링을 한 상품으로 합치고 다이맥스밴드 계정 해금을 추가했다. 기존 기믹도구 중복 SKU는 제거한다.
- Pixelmon 등록 데이터 기준으로 몬스터볼, 지니는 물건, Z크리스탈, 메가나이트를 한 번만 채운다. 몬스터볼은 공용 아이템의 데이터 컴포넌트가 종류를 구분하므로 검색, 구매, 수량 집계에서 변종별 스택을 쓴다. 설치된 서버 JAR에서 볼 아이콘 40개를 준비했다.
- NeoForge 빌드, Fabric 컴포넌트 스택 회귀 테스트와 모의 상점 검증을 통과했다. 다음 run.bat에 서버 적용 예약. 라이브 상품 수와 실제 구매 결과는 미검증이다.

## 메가나이트·몬스터볼 인벤토리 아이콘

- 누락 보고된 메가나이트의 Pixelmon 모델과 텍스처가 JAR 안에 모두 있음을 확인했다. 클라이언트는 렌더 이미지가 전달되지 않으면 대체 아이콘을 남기는 구조였다. 개별 누락 프레임의 원인은 확정하지 않았다.
- 메가나이트 모델의 layer0과 몬스터볼 변종의 ballSprite에서 실제 인벤토리 텍스처 98개를 준비했다. 서버 WebGUI에 적용하고 파일과 원본 텍스처 일치, 볼 GUI 이미지와의 차이, 상점 모의 테스트를 검증했다. 인게임은 확인 대기이며 WebGUI 새로고침으로 적용 가능하다.

## 포켓메이트 메가스톤 실제 등록 ID 변경

- 기존 변경은 EeveeMega의 표시명만 바꿔 등록 ID가 남아 있었다. 호환 모드 0.1.4에서 메가스톤 등록을 pocketmate_mega로 변경하고 NeoForge 별칭을 기존 128개 이름에 추가했다. 모델 및 매핑된 43개 종 데이터 참조와 상점 ID 이관을 검사했다.
- NeoForge 빌드와 단위 테스트, 설치 파일 검증을 통과했다. GitHub Release에 클라이언트 업데이트 JAR와 Windows 설치 마법사를 올리고 배포 목록의 파일 크기·해시를 확인했다. 다음 서버 run.bat에 자동 적용 예약. 라이브 월드 아이템 역호환과 실제 접속은 아직 미검증이다.

## 포켓메이트 메가스톤 상점 추가

- 호환 모드 0.1.4 목록의 포켓메이트 메가스톤 43개를 메가나이트 분류에 한 번만 추가하도록 예약했다. 기존 Pixelmon 메가나이트와 기존 개별 설정은 보존한다. 신규 품목은 기본 구매가로 시작한다.
- 운영 설정 복사본에 43개 추가, 기존 다른 품목 및 가격 유지, 재실행 중복 방지를 확인했다. 실제 서버 적용은 다음 run.bat 실행 후 확인 대기다.

## 포켓메이트 메가나이트 상점 이름과 아이콘

- 호환 모드 0.1.4에 한국어 이름 43개가 있었지만 상점은 Pixelmon 번역만 읽고 있었다. 포켓메이트 메가 한국어 리소스도 검색과 목록 이름에 사용한다.
- 정적 아이콘 목록에 새 네임스페이스 43개를 추가했다. 모델에 지정된 실제 텍스처를 사용하며 자수정 조각을 참조하는 5개는 바닐라 아이템 텍스처를 사용한다. 원본 43개와 일치함을 확인했다.
- 서버 WebGUI 아이콘을 반영하고 NeoForge 이름 패치를 다음 run.bat에 예약했다. 인게임 표시는 확인 대기다.

## 테라스탈오브·다이맥스밴드 상점 아이콘

- 가상 해금 상품 두 종을 Pixelmon 장비 화면 원본 PNG에 연결했다. 서버 WebGUI와 예정된 서버 업데이트의 JS를 갱신했고, 두 파일의 원본 일치 및 매핑을 검사했다. /webgui reload 후 인게임 표시 확인 대기다.

## 원본 메가나이트 아이콘 5종 복원

- 이전 복구 리소스팩에서 54~58번의 서로 다른 원본 스프라이트를 찾았다. 상점 WebGUI를 즉시 갱신하고 NeoForge 0.1.5에서 해당 아이템 모델 5종과 원본 PNG를 복원했다. 다른 게임 리소스 변경은 없다.
- 모의 브라우저에서 배포된 상점 이미지 5종 로드를 확인했다. 빌드·테스트와 설치 검증을 통과했고 GitHub Release 및 원격 팩을 갱신했다. 다음 run.bat에 서버 모드 교체를 예약했다. 인게임 인벤토리는 확인 대기다.

## 다른 플레이어의 Shift+F 메뉴 로딩 실패

- 실행 중인 WebGUI가 19:05에 만든 파일 목록을 유지한 상태에서 19:09에 index.html 등이 교체됐다. WebGUI 서버는 목록의 해시와 현재 파일 해시가 다르면 전송을 거부한다. 새로 파일을 받는 클라이언트의 오류이며 OP 권한과 무관하다.
- 서버 콘솔에서 webgui reload를 실행했다. 19:18에 서버가 446개 파일 목록을 새로 만들었고 기존 접속 클라이언트가 같은 새 리비전을 수신한 것을 로그로 확인했다. 다른 플레이어 PC의 실제 메뉴 열기는 확인 대기다.
- 실행 중인 서버의 WebGUI 파일을 교체한 직후에는 서버 콘솔에서 webgui reload로 파일 목록도 갱신한다.

## 전리품 삭제 설정 재확인

- 전용 서버의 Pixelmon drops.yml에서 delete-unwanted-drops: true를 확인했다. 19:21 서버 시작 완료 로그가 해당 설정 파일의 최종 수정 시각 이후에 기록됐다. 설정을 다시 수정하거나 서버를 재시작하지 않았다. 멀티플레이에서 실제 버튼 동작은 확인 대기다.

## Pixelmon 메가나이트 한국어 이름

- Pixelmon 9.4.3의 한국어 번역에서 누락된 치렁나이트, 픽시나이트, 할비롱나이트, 저리더프나이트, 제라오라나이트를 추가했다. 인게임 한국어 리소스와 상점의 서버측 이름 조회가 같은 번역을 사용한다.
- NeoForge 0.15.6 빌드 및 테스트를 통과했다. 빌드 JAR의 번역 키 5개가 원본 영어에 있고 원본 한국어에는 없는지 확인했다. 전용 서버와 로컬 테스트 인스턴스에 JAR를 배치하고 이전 JAR를 백업했다.
- 다음 서버 및 클라이언트 실행 시 적용된다. 실제 인벤토리 및 상점 표시는 확인 대기이며 원격 클라이언트 팩은 이번에 갱신하지 않았다.
