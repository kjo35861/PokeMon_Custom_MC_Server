## 상점 아이템 설명과 개인 잔액 스코어보드

- 구매 목록에 설명 보기 버튼을 추가하고 구매 수량 창에도 같은 설명을 표시했다. Pixelmon의 한국어 툴팁을 우선 사용하고, 없으면 영어 원문이나 품목 분류별 안내를 표시한다. 계정 해금 상품에는 해금 효과를 표시한다.
- 서버의 개인 지갑 잔액을 개인별 스코어보드 패킷으로 전송한다. 접속 및 잔액 변경은 20틱 간격으로 확인하며 서버 공용 사이드바가 활성화되어 있으면 개인 잔액 사이드바를 양보한다.
- NeoForge 0.15.7 빌드와 테스트, 상점 JS 구문 검사, 모의 브라우저에서 설명 창·구매창·판매 목록·HTML 이스케이프를 확인했다. 운영 서버와 로컬 테스트 인스턴스에 모드를 배치했으며 운영 WebGUI 파일을 교체했다.
- 서버를 실행하거나 재시작하지 않았다. 멀티플레이에서 실제 설명과 스코어보드 표시는 다음 run.bat 실행 후 확인한다.

## 런처 게임 시작 차단 복구

- 로컬 Prism 인스턴스에 수동 배치한 0.15.7과 배포 목록이 승인한 0.15.5가 함께 있었다. 미등록 0.15.7을 인스턴스 백업 폴더로 옮기고 mods 및 resourcepacks의 로드 대상 전체를 배포 목록의 경로·크기·SHA-256과 대조해 불일치가 없음을 확인했다.
- 서버의 0.15.7은 유지했다. 런처나 게임을 실행하지 않았으며 실제 시작·접속은 사용자 확인 대기다.

## 런처 관리 인스턴스 배치 검증 지침

- AGENTS.md에 모드·리소스팩 배치 전후 실제 런처 배포 목록의 경로·크기·SHA-256 대조와 미배포 빌드 격리 원칙을 추가했다. 문서 변경이며 런처와 게임은 실행하지 않았다.

## 상점 구매 품목 설명 툴팁

- 상점 카드의 설명 보기 버튼을 좌측 상단 물음표 아이콘으로 바꿨다. 기존 도움말 툴팁을 재사용하며 구매 수량 창에서도 설명을 읽을 수 있다.
- JS 구문 검사 및 모의 브라우저에서 포인터 진입·이탈, 키보드 포커스·Escape, 설명 이스케이프를 확인했다. 실행 중인 서버 콘솔을 확실히 식별하지 못해 라이브 웹 파일은 교체하지 않았다. 서버 run.bat 다음 실행 시 변경된 WebGUI 4개 파일을 배치하도록 예약했다. 인게임 확인 대기다.

## 상점 카드의 즐겨찾기와 도움말 위치 교체

- 즐겨찾기 별을 왼쪽 위, 설명 물음표를 오른쪽 위로 옮겼다. 서버 WebGUI 배치 파일의 CSS와 캐시 버전을 확인했다. 다음 run.bat 실행에 반영을 예약했으며 인게임 확인 대기다.

## 중복 메가나이트 제거 및 Pixelmon 기본 모델 복원

- 라이츄 X·Y, 픽시, 치렁, 저리더프, 샹델라, 할비롱, 다크라이, 제라오라의 포켓메이트 아이템 등록과 종 데이터 덮어쓰기를 제거했다. 기존 포켓메이트 및 eeveemega 아이템 ID는 대응하는 Pixelmon 아이템의 레지스트리 별칭으로 남겨 저장 데이터 호환을 유지하도록 했다.
- Pixelmon 9.4.3 원본의 나이트→폼→모델 경로 9종을 검증했다. NeoForge 0.1.6 빌드와 생성 팩 검사 9건을 통과했다. 상점 설정 복사본에서 포켓메이트 9개 항목만 제거되고 Pixelmon 가격·규칙이 유지됨을 확인했다.
- 0.1.6 클라이언트 배포 파일의 크기와 SHA-256을 Release에서 확인했다. 실제 접속, 배틀에서의 모델 표시와 기존 아이템 전환은 확인 대기다.
