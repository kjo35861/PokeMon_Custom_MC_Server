- 포켓메이트 관련 증거 파일의 공개용 사본과 SHA-256 목록을 만들었다. PC 경로는 가리고 원본 계정·월드·영상과 제3자 디컴파일 출력은 제외했다.
- EXE·JAR·ZIP과 빌드 캐시를 제외했다. 소스와 재현 방법, 기존 빌드 결과의 해시·검증 기록은 보존한다.
- 증거 정리 스크립트와 업로드 대상 검사 스크립트를 추가했다. 변경이 없는 재실행에서 보고서 시각만 바뀌는 커밋을 만들지 않도록 결정적인 출력을 사용한다.

## 확인한 검증

- 기존 최신 JUnit XML: 전체 50개 통과 기록. 이번 문서 업로드를 위해 Java 테스트를 새로 실행한 것으로 표현하지 않는다.
- 이번 정리 중 재실행: 테마 저장, 차원/요청 조합 80가지, 사용자별 아이콘·배너·기본 스킨·안전한 이미지 경로 검사 통과.
- 업로드 파일 크기·명확한 인증정보 형식·민감 JSON 필드·증거 해시 검사 통과.
- 최신 모드 설치 상태는 `installed`다. 종합 보고서의 이전 설치 대기는 당시 기록으로 보존한다.
- 게임·Prism을 조작하거나 최신 화면을 새로 캡처하지 않았다. 실제 다중 접속 및 1픽셀 어긋남 개선의 게임 내 결과는 미확인이다.

## 정기 기록

사용자가 요청한 매시간 변경 확인·문서 갱신·일반 커밋/푸시의 범위는 [자동화 운영 문서](../AUTOMATION.md)에 정리했다. 실제 활성화는 로컬 Codex 자동화에서 관리하며 이 저장소에 자격 증명을 저장하지 않는다.

- 첫 업로드 커밋: `66c0eec` — 원격 `main`과 커밋 해시가 일치함을 확인했다. 현재 보관 범위는 후속 정리 커밋에 반영한다.
- `포켓메이트 매시간 작업 기록·푸시`를 현재 채팅의 반복 자동화로 생성했다. 최초 설정 상태 `ACTIVE`, 1시간 간격을 확인했다.
- 변경 없는 경우 커밋을 만들지 않고, 문서·증거 정리 및 검사를 통과한 변경만 일반 푸시하도록 했다. 충돌·인증 실패는 보존·보고하며 강제 푸시하지 않는다.
- 자동화 활성화 기록을 별도 후속 커밋으로 등록한다.

## 영토 구매 설명을 도움말로 이동 · 0.12.1

- 선택 방법 설명을 영토 제목 옆 `?`, 구매 조건·가격·금고 보충 설명을 구매 총액 옆 `?`로 이동했다.
- hover·포커스·클릭으로 열고 Esc/외부 클릭/스크롤/화면 갱신으로 닫는다. 설명이 사이드바의 스크롤 경계에 잘리지 않도록 문서 최상위 고정 레이어를 사용하고 화면 가장자리에 맞춰 배치한다.
- 일반·라이트 테마의 공통 변수를 사용하며, 구매 버튼·금액 계산·서버 검사는 유지했다. 오버월드 밖 제한 상태는 숨기지 않는다.
- JavaScript 구문·CSS 파싱과 기존 차원 조건 80개 검사를 수행했다. 게임 조작·브라우저 화면 검증은 하지 않았다.
- 테스트 인스턴스의 화면 파일을 배포하고 패키지를 갱신한다. `/webgui reload` 후 F6으로 적용하며 JAR 변경과 재시작은 필요하지 않다.

## 홈 화면 스크롤 제거 · 0.12.2

- 홈에만 고정 영역 배치를 적용해 제목·타일·안내가 가용 높이를 나눠 사용하도록 변경했다. 기존 타일의 고정 높이로 생기던 넘침을 제거하고 홈의 스크롤을 막았다.
- 홈을 벗어나면 기존 스크롤 모드로 돌아간다. 좁은 화면은 2열·3행, 낮은 화면은 장식과 보조 문구를 줄인다.
- JavaScript 구문과 CSS 파싱, 홈 초기 상태/탭 전환 소스 조건을 확인했다. 게임·브라우저 화면 검증은 하지 않았다.
- 화면 파일만 배포하며 `/webgui reload` 후 F6으로 적용한다. 재시작은 필요하지 않다.

## 프로필 편집 하단 저장 버튼 고정 · 0.12.3

- 프로필 편집 화면에만 고정 높이 flex 구조를 적용하고, 미리보기·보유 항목을 별도 내부 스크롤 영역으로 분리했다.
- 프로필 저장·선택 되돌리기·저장 피드백을 스크롤 영역의 형제 행으로 두어 목록을 내려도 하단에 남고 항목을 덮지 않도록 했다.
- 낮은 화면에서는 제목 영역의 보조 문구와 여백을 줄인다. 다른 탭과 서버 저장 동작은 변경하지 않았다.
- JavaScript 구문, CSS 파싱과 레이아웃 적용 범위·마크업을 확인했다. 게임·브라우저 화면은 자동 조작하거나 검사하지 않았다.
- 화면 파일만 배포하고 `/webgui reload` 후 F6으로 적용한다. 재시작은 필요하지 않다.

## 프로필 편집의 고정 범위 보정 · 0.12.4

- 사용자 화면에서 제목·안내 영역까지 고정된 점을 확인하고, 페이지 전체를 스크롤하는 방식으로 되돌렸다.
- 제목·설명·미리보기·보유 목록·저장 피드백은 함께 스크롤하고 두 버튼만 하단 sticky 행에 남긴다.
- 중첩 스크롤과 낮은 화면에서 제목을 축소·숨기던 규칙을 제거했다.
- JavaScript 구문·CSS 파싱과 버튼 행의 구성·스크롤 범위를 소스로 검사했다. 게임·브라우저 화면은 검증하지 않았다.
- `/webgui reload` 후 F6으로 적용하며 재시작은 필요하지 않다.

## 변경된 프로필에만 둥근 저장 영역 표시 · 0.12.5

- 사용자 후속 지시에 따라 변경사항이 있을 때만 둥근 테두리의 저장·되돌리기 영역을 표시한다.
- 제목·설명·미리보기·목록·피드백은 한 스크롤 영역 안에 두고 버튼 행은 형제 영역으로 분리했다. 버튼이 카드를 가리거나 아래로 카드 일부가 비치지 않는다.
- 초기/되돌린/저장 완료 상태는 숨김, 아이콘·칭호·배너 각 변경은 표시, 저장 중에는 표시하되 버튼을 잠그는 실제 미리보기 로직을 Node VM에서 확인했다.
- JavaScript 구문·CSS 파싱 및 HTML의 버튼 영역/스크롤 영역 분리를 검사했다. 게임·브라우저 화면 검증은 하지 않았다.
- 화면 파일만 변경하여 `/webgui reload` 후 F6으로 적용한다. 재시작은 필요하지 않다.

## 저장 영역 애니메이션과 배경 조정 · 0.12.6

- display none 즉시 전환 대신 grid 행 높이·투명도·세로 이동을 약 0.28초 전환해 아래에서 위로 자연스럽게 나타나고 접히도록 했다.
- 애니메이션 래퍼는 목록 재렌더링에도 유지한다. 닫힌 상태는 inert·aria-hidden으로 접근·클릭을 차단하고 저장 중에는 버튼을 잠근다.
- 버튼 크기에 맞는 내용 너비와 6px 안쪽 여백으로 박스를 줄이고 두 테마에서 구분되는 배경·테두리·되돌리기 버튼 색을 지정했다. 움직임 줄이기와 OS 설정을 반영한다.
- 실제 미리보기 상태 로직의 변경·저장 중·되돌림 및 접근성 상태를 Node VM으로 확인하고 JavaScript 구문·CSS 파싱을 검사했다. 게임·브라우저 시각 검증은 하지 않았다.
- 화면 파일만 변경해 `/webgui reload` 후 F6으로 적용하며 재시작은 필요하지 않다.
