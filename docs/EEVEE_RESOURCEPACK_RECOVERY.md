# EeveeOnline 서버 리소스팩 캐시 확인·복구

조사일: 2026-11-25 (한국 시간). 사용자가 지정한 `.eeveeonline/instances/eeveeonline` 인스턴스를 읽기 전용으로 조사했다. 게임·서버·Prism 실행/종료 및 화면 조작은 하지 않았다.

## 확인 결과

- 일반 `resourcepacks/`는 비어 있다.
- 로컬 저장 월드의 `datapacks/`는 존재하지만 비어 있다. 월드 본문이나 플레이어 데이터를 읽지 않았다.
- `config/`, `defaultconfigs/`에서 별도 팩 ZIP, `pack.mcmeta`, 데이터팩 이름의 파일은 확인되지 않았다.
- `server-resource-packs/`에는 확장자가 없는 리소스팩 캐시 3개가 있다.
- `options.txt`의 선택 목록에는 `resourcepacksync_server`가 있다. 최근 접속 로그의 캐시 참조는 `1dda7321ec9af73720faa269035d23a5d2985961`과 일치한다. 이는 저장된 설정·로그에 대한 관찰이며 현재 실행 중인 게임의 메모리 상태를 관찰한 결과는 아니다.
- 인스턴스 모드 목록에서 Pixelmon `9.3.12`와 EeveeMega `1.1.0` 파일명을 확인했다. 이 조합의 게임·서버 호환성을 직접 시험한 것은 아니다.

| 캐시 ID | 원본 크기 | 중앙 디렉터리 엔트리 | `assets/eeveemega/` 엔트리 | `data/` 엔트리 |
|---|---:|---:|---:|---:|
| `1dda7321ec9af73720faa269035d23a5d2985961` | 776,697,399바이트 | 5,445 | 93 | 0 |
| `2bb824cbeb40922e57e03bfd4cecbfa1b47e6d6c` | 381,980,765바이트 | 4,173 | 0 | 0 |
| `fd1798a171654dfeec35501f08c547db3bc191a2` | 1,341,476,309바이트 | 4,075 | 0 | 0 |

`resourcepacksync`의 `ClientPacketHandler.getCacheDir()`는 게임 폴더 아래 `server-resource-packs`를 선택하며, 파일명은 서버가 전달한 SHA-1의 소문자 값이다. `ResourcePackLoader`는 이 파일을 `resourcepacksync_server`라는 팩 ID로 로드한다. 따라서 비어 있는 일반 리소스팩 폴더만 확인하면 이 서버 팩을 놓칠 수 있다.

## 메가진화 자산

최근 로그와 일치하는 캐시에는 다음 자료가 있다.

- `assets/eeveemega/`에 아이템 모델·텍스처·번역 93개.
- `assets/pixelmon/textures/pokemon/` 아래 메가 폼의 모델 파일 91개. 모델 파일 경로를 기준으로 종족 42종, 폼 조합 43개가 확인된다. 완성도나 배틀 가능 포켓몬 수를 뜻하지 않는다.
- 예: 메가장크로다일, 메가드닐레이브, 메가앱솔 Z, 메가한카리아스 Z, 메가루카리오 Z의 모델 경로가 존재한다.
- `data/` 엔트리는 없다. 외형 리소스팩을 확보한 것이며 서버의 종족·폼·능력치·진화 조건 데이터팩을 복구한 것은 아니다.

## 표준 ZIP 복구

원본 캐시의 중앙 디렉터리 파일명과 로컬 헤더 파일명이 다르고, 해제 크기·CRC 정보가 실제 값과 다르다. 예를 들어 `pack.mcmeta`의 선언 크기는 1,337바이트지만 실제 DEFLATE 해제 결과는 251바이트다. 일반 Python ZIP 읽기는 이 파일명 차이로 `BadZipFile`을 보고했다.

원본을 수정하지 않고 중앙 디렉터리의 안전한 경로와 압축 데이터 오프셋을 사용하여 실제 스트림을 읽고, 별도 표준 ZIP으로 재작성했다. 절대 경로·상위 경로·중복 이름을 거부하고, 해제 크기 제한과 DEFLATE 종료 여부를 검사했다.

| 검증 항목 | 실제 결과 |
|---|---|
| 원본 SHA-1 | `1dda7321ec9af73720faa269035d23a5d2985961` — 캐시 파일명과 일치 |
| 원본 SHA-256 | `ab0ad54a717fef8dc037977ffd6ed81713494e6deabe33e9d908e82c2f9fd8db` |
| 복구 ZIP | `eevee-server-resourcepack-recovered.zip` |
| 복구 ZIP 크기 | 778,172,765바이트 |
| 복구 ZIP SHA-256 | `d4146d3a1eeebfc6f9064ee26948d7073621494255c6b0826fbbf3e73d2e3e8b` |
| 복구 엔트리 수 | 5,445개, 전체 읽기·CRC 검사 통과 |
| 실제 해제 크기 합계 | 1,291,834,532바이트 |
| `pack.mcmeta` | JSON 파싱 성공, `pack_format=34`, 설명 `ItemsAdder`, 기존 오버레이 선언 보존 |
| 원본 보존 확인 | 작업 전후 원본 파일 크기·수정 시각 동일. 원본에 쓰기 작업 없음 |

출력은 사용자 Downloads 아래 `eevee-resourcepack-recovered-2026-11-25/`에만 저장했다. 같은 폴더의 `recovery-manifest.json`에는 각 파일의 실제 크기·SHA-256·CRC와 전체 복구 결과를 기록했다. 원본 캐시, 복구 ZIP, 개별 자산, 전체 로그, 개인 월드는 Git 저장소에 추가하지 않았다.

## 적용 범위와 한계

리소스팩 추출·구조·무결성 검사는 완료했다. 게임 내 모델 렌더링, Pixelmon 폼 매핑, 서버 배틀 동작은 미검증이다. 실제 서버 데이터팩이나 서버 플러그인은 클라이언트의 이 경로에서 확보하지 못했다. 온라인 서버에 접속하거나 추가 다운로드를 시도하지 않았다.

인스턴스 설정과 모드를 바꾸지 않았으므로 이 조사만으로 재시작할 필요는 없다. 복구 ZIP을 실제 게임에 설치하거나 포켓메이트 서버에 적용하는 작업은 수행하지 않았다.
