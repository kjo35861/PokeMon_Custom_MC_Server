# 메뉴 0.17.0 · 외부 프로필과 임무 카드

프로필카드 DOM 하나를 메뉴 창 밖 body 바로 아래에 배치한다. 화면 상단 중앙(12시 방향)에 표시하고 홈·상점·임무·설정·프로필 편집·영지 관리에서도 유지한다. 기존 배너·칭호·스킨·HP 업데이트는 같은 ID를 사용한다. 영지 화면에서도 프로필 편집 버튼을 누르면 편집 화면으로 이동한다.

실제 카드 높이를 ResizeObserver로 측정해 메뉴/영지 창이 침범하지 않도록 위 공간을 예약한다. 프로필카드를 메뉴 내부에서 제거해 콘텐츠 높이를 확보하고 기능 제목·상단 간격을 줄였다.

임무 화면은 5개 세로형 카드를 한 줄로 나란히 배치하고, 그 아래 전체 너비의 가로형 최종 완료 보상 카드를 둔다. 큰 중복 제목과 돌아가기 버튼은 임무 화면에서 생략하고 왼쪽 홈 탭으로 돌아간다. 설명이 긴 광석·돌·이동 문구는 화면에서 짧게 표시하며 원문은 hover/focus 도움말로 확인한다. 진행도·교체·수령 서버 로직은 변경하지 않는다.

일반 창에서 5개 임무와 최종 보상을 한 화면에 표시한다. 760px 이하의 매우 좁은 창, 또는 낮고 좁은 창의 큰 글자 설정에서는 내용을 자르지 않고 세로 스크롤을 허용한다.

검사: headless mock 화면에서 1920×1080, 1440×900, 1366×768, 1280×720 각각 100%/160%, 854×480 100% 총 9개 조합을 확인. 긴 임무 문구, 5개 카드 동일 행, 최종 보상 하단 위치, 내부 스크롤/겹침 없음 검사 통과. 일반 메뉴·영지 화면의 외부 프로필과 영지에서 프로필 편집 이동, 기존 프로필 변경·저장/취소 검사도 통과. 실제 Minecraft 화면 검사는 하지 않았다.

프로필 검사에는 수정 사항이 있을 때만 저장 버튼이 나타나는 기존 정책을 반영해 실제 미리보기 변경 후 저장 버튼 도달성을 확인했다.

적용: 테스트 인스턴스 웹 자산 복사 및 동일성 확인. Java 모드 변경은 없으므로 `/webgui reload` 후 메뉴를 다시 열면 된다. 재시작은 필요 없다. 사용자 최종 화면 확인 대기이므로 새 배치를 README 완료 항목으로 표시하지 않는다.
