# 컨셉 명확화·겹침 정리 · 7차 시안

상태: **사용자 디자인 검토 대기 · 실제 게임 미적용**.

사용자가 지목한 뮤츠·앤테이·가이오가·블리자포스·네크로즈마·뮤·레지에레키·위유이·제라오라 9종을 수정했다. 이어진 지시에 따라 토네로스의 회오리처럼 개념이 읽히는 작은 그림을 우선했다. 전체 94종 비교판을 다시 보고 보석과 나선이 뭉개지던 테오키스도 수정해 총 10종을 바꿨다. 나머지 84종 PNG와 모든 칭호 문구·색은 이전 시안 그대로다. 이것은 검토 범위와 변경 범위의 기록이며, 나머지 84종의 디자인이 최종 승인되었다는 뜻은 아니다.

수정한 핵심 그림은 `수정 마크 기준.md`에 정리했다. 뮤츠는 인공 유전자 실험 플라스크, 앤테이는 분화하는 화산, 가이오가는 큰 파도, 블리자포스는 편자와 분리된 눈 결정, 네크로즈마는 빛이 모이는 프리즘, 뮤는 정돈된 DNA, 레지에레키는 큰 번개, 위유이는 옥 눈을 가진 물고기, 제라오라는 발톱과 분리된 번개, 테오키스는 은하 나선으로 구성했다. 전부 프로젝트의 도형 코드에서 직접 그렸다.

## 자료

- `changed-marks-comparison.png`: 10종 수정 전후와 24/16/12px 비교. 브라우저나 게임 화면이 아니라 PNG로 만든 비교판이다.
- `legendary-clear.png`, `mythical-clear.png`: 전체 94종 재검토용 비교판.
- `symbol-rationale.json`, `수정 마크 기준.md`: 마크 구성과 수정 이유.
- `icons/`, `glyph-map.json`, `resource-pack/`, `tellraw-examples.txt`: 투명 PNG 및 게임 미설치 글꼴 초안. 명령 예시는 실행하지 않았다.
- `preview.fragment.html`, `preview-data.json`: 수정한 전설 7종과 환상 3종을 각 목록 위에 먼저 표시하는 검토 화면.

생성: `python tools/build_clear_title_marks.py`.

정적 검사: `python tools/check_line_title_pngs.py docs/design/legendary-titles/clear-marks-v7`.

검토 화면 모의 검사: `node tools/check_title_designs.cjs docs/design/legendary-titles/clear-marks-v7`.

94개 마크의 고유 도형, 기존 메타데이터 보존, 정확히 10종 PNG 변경/84종 PNG 불변, PNG·폰트·문자·명령 예시 정합성을 확인했다. 모의 DOM 188개 선택/테마/설명 상태를 검사했다. 전체 비교판 2장과 수정 전후/축소 비교판을 직접 열어 확인했고, 뮤츠·네크로즈마·테오키스의 추가 정리 후 비교판도 다시 확인했다. 이는 제작자 검토이며 사용자 컨셉 적합성 승인이나 실제 게임 가독성 검증이 아니다. 12/16/24px 비교도 Minecraft 렌더러 검사로 간주하지 않는다.

게임·Prism 실행/종료/조작, 모드·WebGUI 실행 파일·설치 파일·월드 수정은 하지 않았다. 과거 시안은 보존한다. 최종 검토가 진행 중이므로 README 완료 기능에 추가하지 않는다.
