# 포켓몬 전용 상징 마크 · 6차 시안

상태: **사용자 디자인 검토 대기 · 게임 미적용**.

사용자의 최신 정정은 외형을 그대로 그리는 것이 아니라 각 포켓몬의 특징·상징과 칭호 의미가 결합된 전용 마크를 만드는 것이다. 5차 얼굴/몸 그림은 이번 방향에서 제외했다. 원화를 참고하며 확인한 특징을 문장으로 압축하고, 2차 기하학적 문양 중 의미가 맞는 구조를 바탕으로 필요한 마크를 재구성했다. 모든 마크를 원화처럼 보이게 하거나 전부 새 도형으로 그렸다고 주장하지 않는다.

## 디자인 기준

각 종은 한 개의 중심 상징과 이를 구별하는 고유 특징을 묶는다. 예를 들어 비크티니는 귀의 V와 승리, 디아루가는 고유 다이아와 시침, 크레세리아는 초승달과 세 고리, 라이코는 송곳니와 번개, 레지드래고는 용 턱과 핵을 사용한다. 얼굴의 눈·코나 몸 전체의 윤곽으로 종을 표현하는 방향은 사용하지 않는다. 가면·너트·솥·검처럼 그 자체가 종의 상징인 물체는 마크 요소로 사용한다.

`symbol-rationale.json`과 `종별 마크 의미.md`에 94종의 상징 요소·칭호와의 관계를 모두 남겼다. 검토 화면에서도 선택한 포켓몬의 마크 구성과 의미를 볼 수 있다. 이 설명은 디자인 의도이며 사용자가 실제로 포켓몬을 즉시 식별했다고 검증한 결과가 아니다.

- 문구·글자색·전설 71종/환상 23종 구분은 유지한다.
- 마크는 24 좌표계의 선 문양을 투명 PNG 48×48로 렌더링한다.
- 종 단위 시안이며 다른 폼별 별도 지급은 구현하지 않는다.
- `resource-pack/`, `glyph-map.json`, `tellraw-examples.txt`는 대상 1.21.1용 미설치 글꼴 초안이다.
- `legendary-marks.png`, `mythical-marks.png`는 검토 비교판이며 게임 화면이 아니다.

생성: `python tools/build_symbol_title_marks.py`.

검사: `python tools/check_line_title_pngs.py docs/design/legendary-titles/symbol-marks-v6`, `node tools/check_title_designs.cjs docs/design/legendary-titles/symbol-marks-v6`.

94개 고유 마크·상징 근거 존재와 PNG/글꼴/문자 매핑/명령 예시를 정적으로 검사하고 검토 화면의 188개 선택·테마·설명 상태를 모의 DOM으로 확인했다. 비교판 2장을 직접 열었으며 마지막으로 단순화한 제라오라의 발톱/번개 PNG도 열어 확인했다. 실제 브라우저·게임 렌더링·작은 채팅 크기의 종 식별성은 검사하지 않았다.

기존 공개 시안과 기록은 보존한다. 모드·WebGUI 실행 파일·설치된 게임·월드는 변경하지 않았으며 게임/Prism 조작이나 명령 실행도 하지 않았다. 디자인 승인 및 게임 검증 전이므로 README 완료 기능에는 추가하지 않는다.
