# 요청한 5종 추가 수정 · 8차 시안

상태: **사용자 검토 대기 · 게임 미적용**.

뮤·지라치·기로치·게노세크트·자루도만 수정했다. 앞서 수정한 7차 시안의 다른 89종 PNG와 모든 칭호 문구·색은 유지한다.

| 포켓몬 | 그림 | 수정 의도 |
|---|---|---|
| 뮤 | 기원의 세포와 안의 유전자 한 가닥 | 작은 가로선이 많은 이중 나선을 덜어 생명의 시작이라는 컨셉을 단순화 |
| 지라치 | 소원의 별과 별빛 자취 | 별 꼭짓점과 겹치는 끈을 제거하고 별 자체를 크게 표현 |
| 기로치 | 깃털과 분리된 사슬 고리 | 깃 속 잔가지와 교차 고리를 줄여 유혹의 깃이라는 개념을 먼저 전달 |
| 게노세크트 | 큰 포신과 작은 조준점 | 고대의 포신을 분명한 포 모양으로 표현하고 부속 마디를 제거 |
| 자루도 | 덩굴이 감긴 손 | 추상 교차 매듭을 손과 손목 덩굴로 바꾸어 덩굴손과 직접 연결 |

`five-marks-comparison.png`에서 이전/수정/24·16·12px 비교를 볼 수 있다. 비교판은 직접 렌더링한 그림이며 게임 화면이 아니다. `symbol-rationale.json`에는 나머지 종을 포함한 전체 94종의 근거를 유지한다. 검토 화면은 이번 5종을 각 분류에서 먼저 표시한다.

생성: `python tools/build_five_title_marks.py`.

검사: `python tools/check_line_title_pngs.py docs/design/legendary-titles/five-marks-v8`, `node tools/check_title_designs.cjs docs/design/legendary-titles/five-marks-v8`.

정확히 5개 PNG 변경/89개 불변과 문구·색 불변, PNG/폰트 시트/문자/명령 JSON 정합성 및 모의 DOM 188개 선택·테마·설명 상태를 확인했다. 수정 전후/축소 비교판을 직접 열었다. 실제 브라우저·게임 가독성·사용자의 컨셉 적합성 승인은 미검증이다.

이 폴더의 리소스 팩과 명령 예시는 미설치·미실행 초안이다. 게임·Prism·모드·WebGUI 실행 파일·월드는 조작하거나 변경하지 않았다. 이전 시안과 검증 기록은 보존하고, README 완료 기능에는 아직 추가하지 않는다.
