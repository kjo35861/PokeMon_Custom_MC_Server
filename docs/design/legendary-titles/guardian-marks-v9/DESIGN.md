# 섬지기·해방·수련·독룡 및 추가 요청 · 9차 시안

상태: **사용자 검토 대기 · 게임 미적용**.

최초 요청 5종에 진행 중 추가된 레쿠쟈·블리자포스·레이스포스를 포함해 8종을 수정했다. 실버디는 추가 정정에 따라 자물쇠를 제외하고, 두 말 포켓몬도 발굽을 직접 그리는 안에서 벗어났다.

| 포켓몬 | 수정한 마크 |
|---|---|
| 실버디 | 펼쳐지는 세 깃. 자물쇠·구속구는 사용하지 않음 |
| 카푸브루루 | 황소 뿔과 분리된 숲의 잎 |
| 카푸느지느 | 펼쳐진 조개 |
| 치고마 | 손목에 수련 띠를 두른 주먹 |
| 무한다이노 | 용의 송곳니와 독방울 |
| 레쿠쟈 | 천공을 흐르는 용의 문장 |
| 블리자포스 | 눈 덮인 빙산. 발굽·편자 제외 |
| 레이스포스 | 떠도는 망령. 발굽·편자 제외 |

`changed-marks-comparison.png`는 이전/수정/24·16·12px 비교이며 게임 화면이 아니다. `symbol-rationale.json`에 전체 94종의 의미를 유지한다. 이전 8차의 다른 86종 PNG와 모든 칭호 문구·색은 바이트/메타데이터 비교로 불변을 확인했다.

생성: `python tools/build_guardian_title_marks.py`.

검사: `python tools/check_line_title_pngs.py docs/design/legendary-titles/guardian-marks-v9`, `node tools/check_title_designs.cjs docs/design/legendary-titles/guardian-marks-v9`.

PNG·글꼴 시트·문자 매핑·명령 예시 정적 검사와 모의 DOM 188개 선택·테마·설명 상태 검사를 통과했다. 비교판을 직접 열었고 사용자 추가 요청과 형태 보완 뒤 다시 열어 확인했다. 실제 브라우저·게임에서의 표시와 사용자 디자인 적합성 승인은 미검증이다.

게임/Prism·모드·WebGUI 실행 파일·월드는 조작하거나 변경하지 않았다. 리소스 팩과 명령 예시는 미설치·미실행 초안이며 이전 공개 시안·검증 기록은 보존한다. README 완료 기능에는 아직 추가하지 않는다.
