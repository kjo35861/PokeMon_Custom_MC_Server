# 매시간 작업 기록·푸시

사용자 요청(2026-11-24): 지정 GitHub 저장소에 현재까지의 소스·작업 과정·증거 자료를 올리고, 이후 매일 1시간마다 작업한 내용이 있으면 자동으로 푸시한다.

## 실행 방식

현재 Codex 채팅에 연결된 로컬 반복 자동화를 사용한다. 주기는 1시간이며 매일 모든 시간대에 적용한다. GitHub Actions가 사용자 PC의 미커밋 파일을 가져가는 방식이 아니다. 원격은 `https://github.com/kjo35861/PokeMon_Custom_MC_Server.git`, 작업 브랜치는 `main`이다.

매 실행은 다음 순서를 따른다.

1. 작업 폴더와 원격을 확인하고, 기존 변경·커밋·증거 자료 갱신 여부를 확인한다.
2. `python tools/prepare_evidence.py`로 공개용 증거를 갱신한다. 원본이 없는 새 체크아웃에서는 보관 중인 증거를 지우지 않는다.
3. 실제 변경이 없고 푸시할 커밋도 없으면 종료한다. 시각만 바꾼 문서나 빈 커밋을 만들지 않는다.
4. 변경한 기능·이유·실제 검사·한계·적용 방법을 README와 날짜별 작업일지에 반영한다.
5. 변경에 맞는 구문·로직 검사를 수행한다. 코드 변경 없이 검사를 새로 통과한 것처럼 기록하지 않는다.
6. `python tools/check_publish.py`로 업로드 대상과 증거 해시를 확인한다.
7. 검사를 통과한 프로젝트 변경만 커밋하고 일반 `git push`를 수행한다. 이미 커밋되어 원격보다 앞선 작업도 푸시한다.

## 충돌·인증·실행 환경

- 강제 푸시, 원격 이력 삭제, `git reset --hard`, 사용자 변경 폐기는 하지 않는다.
- 원격이 앞서거나 이력이 갈라져 일반 푸시가 불가능하면 현재 작업을 보존하고 원인을 알린다.
- 인증 실패 시 토큰을 문서·로그에 출력하거나 저장하지 않는다. Git Credential Manager의 기존 인증을 사용한다.
- PC 절전·앱 종료·네트워크 또는 인증 문제 시 실행이 지연되거나 실패할 수 있다. 이 자동화는 외부 상시 서버가 아니다.
- 사용자 요청에 따라 게임·Prism을 켜거나 끄고 게임 화면을 자동 조작하지 않는다.
- 보안 검사나 충돌이 발생했는데도 푸시 완료라고 보고하지 않는다.

## 제외 자료

계정·토큰·쿠키·실제 월드·재화 데이터, 개인 설정, 원본 영상, 빌드 캐시와 대용량 EXE·JAR·ZIP은 제외한다. 보고서의 절대 PC 경로는 공개용 사본에서 가린다. 글꼴·이미지와 타사 코드의 출처·라이선스 표시는 유지한다.

설정의 실제 활성화 상태는 로컬 Codex 자동화에서 관리한다. 저장소에 API 키나 자동화 실행 자격 증명은 넣지 않는다.
