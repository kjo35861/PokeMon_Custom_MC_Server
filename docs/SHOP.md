# 포켓메이트 상점

메뉴 0.20.0 / Fabric 1.21.1 모드 0.12.0. 코드·레지스트리·모의 화면 검사는 완료했으며, 실제 게임에서의 거래/아이콘 표시는 사용자 확인 대기입니다. Pixelmon/NeoForge 포팅을 의미하지 않습니다.

## 카테고리와 가격

- 바닐라: 건축블럭 / 색깔블럭 / 장식블럭 / 광물 / 농작물.
- 포켓몬: 몬스터볼 / 지니는 물건 / Z크리스탈 / 메가나이트. 분류만 있으며 상품은 없습니다.
- 건축: 기본 상태 외형이 완전한 사각 블록. 계단·반블럭은 제외합니다.
- 색깔: 16색 양털·카펫·테라코타·콘크리트·유리·셜커·침대·양초·현수막 및 염색 가능한 기본형.
- 장식: 나머지 배치 가능한 바닐라 블록(꽃·횃불 등). 운영자/월드 제어용 블록은 제외합니다.
- 광물: 석탄, 철/금/구리 원석, 다이아몬드, 에메랄드, 청금석, 레드스톤, 석영, 자수정 조각, 고대 잔해, 부싯돌, 발광석 가루. 주괴·조각·네더라이트 파편 등 제련/가공 아이템은 없습니다. 광석 블록도 구매 목록에 넣지 않습니다.
- 농작물 구매: 6종 씨앗/꼬투리 및 당근·감자·코코아·네더사마귀·열매·사탕수수·코러스 꽃 등 실제 심을 수 있는 재료. 수확물/씨앗류는 판매 목록에 별도로 표시됩니다. 횃불꽃·벌레잡이풀은 장식 분류에서 구매하고 농작물로 판매합니다.
- 모든 구매 단가100원, 모든 판매 단가50원. 광물/씨앗 구매가도 우선100원으로 둔 임시값입니다.
- 무한 차익을 막기 위해 사용자가 승인한 광물 압축 블록 제외 정책과 같은 취지로 건초 더미·수박 블록·발광석·대나무 블록·네더 사마귀 블록도 구매에서 제외합니다. 아이템 분해로 바로 판매 차익이 생기는 경로를 줄이기 위한 목록입니다.

전체 목록은 [shop-catalog.csv](shop-catalog.csv). 레지스트리 기준769종, 구매763종, 판매40종이며 구매/판매 중복을 포함합니다. 목록은 Minecraft 1.21.1 바닐라 레지스트리로 생성됩니다. 아이템 이름은 설치된 1.21.1 한국어 언어 항목을 참조했으며 게임 텍스처를 저장소나 메뉴 ZIP에 재배포하지 않습니다.

## 거래 동작

상품별 수량 입력(1~2,304개), 1/16/64개 바로 선택, 합계 확인 후 확정합니다. 한 페이지24종이며 한글 이름/아이템ID 검색과 페이지 이동을 제공합니다. 기존 영지 금고에서 사용하는 포켓메이트 개인 지갑과 같은 잔액을 사용합니다. 자동으로 테스트 재화를 지급하지 않습니다.

서버가 등록품목·구매/판매 허용·최신 가격 버전·정수 수량·인벤토리 공간·보유 수량·잔액을 다시 검사합니다. 브라우저가 가격/합계/지갑을 결정하지 않습니다. 판매는 가방/단축바36슬롯의 기본 아이템만 처리하며 이름·인챈트·추가 컴포넌트가 있는 스택, 장비/보조손, 열린 보관함은 자동으로 가져오지 않습니다.

모든 처리는 서버 스레드에서 실행됩니다. 인벤토리 계획을 복사본에서 검증하고, 지갑 저장 실패/금액 부족 시 원래 인벤토리로 복원합니다. 성공 후 플레이어 저장을 요청합니다. 서버 실행 중 중복 요청ID/짧은 연속 요청을 차단합니다. 지갑 파일과 Minecraft 플레이어 파일은 서로 다른 저장소이므로 강제 전원 종료까지 포함하는 두 파일 간 원자적 거래 보장은 아닙니다.

아이콘은 클라이언트의 설치된 게임/리소스팩에서 작은 PNG 텍스처를 읽어 표시합니다. 개당16KB·한 응답48KB로 제한하며 리소스가 없거나 큰 경우 카테고리 아이콘이 표시됩니다. 별도 외부 이미지 서버/인터넷은 필요 없습니다.

## 추후 가격 변동

첫 월드 시작 시 config/pocketmate-shop.json이 만들어집니다. 현재 랜덤 기능은 꺼져 있습니다. 설정 변경은 서버/싱글 월드를 다시 시작해야 반영됩니다.

```json
{
  "buyBase": 100,
  "sellBase": 50,
  "randomEnabled": false,
  "intervalSeconds": 3600,
  "deviationPercent": 15,
  "seed": 88301361644884,
  "buyPrices": {},
  "sellPrices": {}
}
```

randomEnabled를 켜면 판매 가격만 서버 시각의 고정 주기별로 기준가±편차 범위에서 정해집니다. 같은 아이템·같은 주기는 재접속/서버 재시작으로 가격이 재추첨되지 않습니다. seed는 운영자가 고정 유지합니다. intervalSeconds는60~604800초, deviationPercent는0~40입니다. 개별 아이템 기준가는 buyPrices/sellPrices에 minecraft:diamond 같은ID와 정수 금액을 넣을 수 있습니다. 판매가는 반드시 구매가보다 작아야 하며, 변동 판매가도 구매가 아래로 제한됩니다.

가격 버전이 바뀐 뒤 예전 가격으로 거래를 확정하면 서버가 거절합니다. 새로고침 후 최신 가격을 보고 다시 확정해야 합니다. 클라이언트가 오래된 가격으로 자동 결제하지 않습니다.

## 적용과 검증

이번 변경은 웹 파일뿐 아니라 모드 코드가 추가되므로 /webgui reload만으로 적용되지 않습니다. 테스트 인스턴스의 모드0.12.0 및 웹 파일 설치 바이트 일치를 확인했으며 다음 게임 실행에 반영됩니다. 게임 실행/종료/월드 조작은 에이전트가 수행하지 않았습니다.

새 테스트 월드에서 재화가 필요하면 관리자/치트 권한과 freeTestMode가 켜진 상태에서 기존 `/pmestate testcredit @s 10000`을 사용할 수 있습니다. 실제 재화/아이템을 변경하는 명령이므로 자동 실행하지 않았습니다.

검사: Java97개(기존90+상점7), 실제 바닐라 레지스트리 분류, 고정/주기별/아이템별 가격, 스택 합치기·공간 부족·추가정보 아이템 보호·저장 실패 복원·공유 지갑 영속화. 모의 화면에서 구매/판매·잔액 부족·가격 갱신·수량·한글 검색·포켓몬 빈 분류·페이지 이동·4화면 크기·구독 정리를 확인했습니다. 실제 게임 거래·아이콘 렌더와 장기 경제 운영 검증은 남아 있습니다.
