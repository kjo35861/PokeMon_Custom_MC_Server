# 포켓메이트 플레이어 배포

플레이어 ZIP은 1.21.1 / NeoForge 21.1.248과 접속 주소 26.109.5.37:25565를 사용한다. Prism 설치 및 Microsoft 계정 로그인 후 Prism을 종료하고, ZIP을 모두 푼 폴더의 런처를 실행한다. 사전 순정 인스턴스 없이 전용 인스턴스를 생성하며 설정·팩 구성은 배포 파일에 포함된다.

한국어, 채팅 크기·간격, Shift+F, 리소스팩, 서버 항목은 최초 생성에만 적용한다. 이후 파일 설치와 검증은 client-pack.json이 관리한다. 주소에 도달할 수 있는 네트워크 연결이 필요하다.

빈 Prism 데이터 폴더를 사용한 자동 생성, 기존 옵션 보존 및 백엔드 60개 검사 통과. ZIP의 포함 로컬 파일 해시 및 압축 무결성 확인. 별도 PC와의 접속은 미검증.


설치 연동판에서는 Prism 미설치 시 게임 시작 버튼이 WinGet의 공식 Prism 패키지 설치를 시작한다. 설치 경로를 다시 확인하고 인스턴스를 준비한 뒤 Prism을 열어 계정 추가를 안내한다. 빌드와 백엔드60개 통과. 실제 WinGet 설치 및 Microsoft 실계정 인증 미검증.


Windows 배포용 Pocketmate-Setup-1.21.1.exe는 설치 경로 선택과 기본 선택된 바탕화면 바로가기를 제공한다. 새 폴더 또는 빈 폴더를 선택한다. 격리된 사용자 지정 경로에 실제 내장 팩 추출 및 바로가기 대상·작업 경로 검증을 완료했다. 빌드 명령은 python snowfrost_launcher/build_player_setup.py <player.zip> <setup.exe> 이다.
