# 포켓메이트 클라이언트 배포 목록

`client-pack.json`은 포켓메이트 런처가 시작할 때와 게임을 실행하기 직전에 읽는 파일입니다. 파일은 지정된 크기와 SHA-256으로 확인합니다.

- 각 항목의 `path`는 게임 인스턴스 기준 경로입니다.
- `local:` 주소는 최초 설치 파일에 이미 포함된 파일에 사용합니다. 모드가 갱신되면 다운로드 가능한 HTTPS 주소, 새 크기, 새 SHA-256을 같은 항목에 넣으세요.
- 파일을 배포처에 먼저 올린 뒤 이 목록과 `packVersion`을 갱신합니다. 직접 만든 파일은 GitHub Releases, 배포가 허용된 외부 모드는 공식 배포 주소를 쓸 수 있습니다.
- 클라이언트에서 제거할 모드는 목록에서 빼면 다음 업데이트에 기존 관리 파일이 제거됩니다. 서버 전용 파일은 목록에 넣지 않습니다.
- 현재 설치본이 사용하는 Minecraft 1.21.1과 NeoForge 21.1.248은 고정되어 있습니다.

목록 URL을 지원하는 설치본을 한 번 설치하면 이후 팩 변경은 런처에서 받을 수 있습니다. 공개 목록에는 계정정보, 개인 파일, 서버 월드가 들어가지 않습니다.
