포켓메이트 · WebGUI 사용 안내 (2026-11-23 확인)

대상: mc-webgui/webgui의 WebGUI 2.0.0+mc1.21.1-fabric
MC: Java 1.21.1 / Fabric Loader 기본 0.20.1 / Java 21
모드는 아직 설치하지 않았으며, 아래는 설치 및 제작 안내입니다.

1. 설치
서버 mods 폴더와 모든 참가자의 Fabric 클라이언트 mods 폴더에
동일한 1.21.1 Fabric용 WebGUI와 호환 Fabric API를 넣습니다.
Prism의 모드 다운로드 화면에서 Minecraft 1.21.1/Fabric 필터를 확인하세요.
브라우저 엔진은 WebGUI 2.0에 포함되어 있어 별도 MCEF/Rinku 모드를 추가할 필요가 없습니다.
브라우저 본체는 최초 클라이언트 실행에서 다운로드됩니다.

다운로드: https://modrinth.com/mod/webgui/version/LUSurAPp
2.0 변경 기록을 기준으로 안내합니다. 일부 일반 가이드는 1.x 설정을 설명합니다.

2. 메뉴 파일 위치
Fabric 서버를 한 번 실행하면 아래 폴더와 예제가 생성됩니다.
  서버폴더/config/webgui/server.json
  서버폴더/config/webgui/web/index.html

index.html이 메뉴 화면입니다. HTML/CSS/JavaScript로 수정합니다.
이미지와 스크립트는 ./assets/icon.png 같은 상대 경로를 쓰세요.
별도 웹 호스팅 없이 Minecraft 접속 연결을 통해 메뉴 파일을 전달할 수 있습니다.

3. 메뉴 주소 설정
server.json의 기존 내용을 보존하면서 아래 항목을 수정합니다.

{
  "mainMenuUrl": "webgui://index.html",
  "serveBundledPages": true,
  "autoHudOnJoin": false
}

이 코드는 수정할 항목의 예시이며 기존 설정 전체를 지우라는 뜻은 아닙니다.
WebGUI 2.0은 webgui://index.html을 사용합니다.
구형 가이드의 webgui:/index.html 또는 webgui:index.html은 2.0에서 허용하지 않습니다.
autoHudOnJoin=false는 접속 즉시 HUD를 표시하지 않고 필요할 때 메뉴만 여는 구성입니다.
외부 웹사이트를 쓰려면 mainMenuUrl에 실제 https://... 주소를 지정할 수도 있습니다.

4. 먼저 F6으로 테스트
WebGUI가 설치된 클라이언트로 서버에 접속한 뒤 F6을 누릅니다.
운영자는 아래 명령으로 본인 메뉴를 열어 테스트할 수도 있습니다.
  /webgui gui @s webgui://index.html

파일/설정을 바꾼 뒤 적용:
  /webgui reload

위 관리 명령은 권한이 필요합니다. 서버 콘솔에서는 @s 대신 플레이어 이름을 사용하세요.
전체 메뉴는 Esc로 닫을 수 있습니다.

5. Shift+F 메뉴
기본 메뉴 키는 F6입니다. 설정 → 조작 → 키 설정 → WebGUI에서 단일 키를 바꿀 수 있습니다.
현재 기본 키 등록 코드에는 Shift+F를 구분하는 modifier 조건이 없습니다.
F로만 바꾸면 F 단독과 구분되지 않으므로 전용 보조 Fabric 모드로 구현하는 것이 적합합니다.

권장 구현 흐름:
- 게임 중 화면이 열려 있지 않을 때 Shift를 누른 상태의 F 입력을 한 번 감지합니다.
- 포켓메이트 메뉴 열기 요청을 서버로 보냅니다.
- 서버는 해당 플레이어에게 WebviewApi.openGui(player, "webgui://index.html")를 호출합니다.
- 키를 누르고 있어도 반복해서 열리지 않게 하고, 채팅/인벤토리에서는 동작시키지 않습니다.
- Shift+F에서는 기본 F의 양손 아이템 교환 동작을 함께 실행하지 않게 처리합니다.
- 클라이언트 요청은 포켓메이트 서버에 접속했을 때만 처리합니다.

WebviewApi는 서버 스레드에서 호출하는 API입니다.
보조 모드를 클라이언트와 서버에 배포하고, 클라이언트 입력과 서버 처리를 연결합니다.
이것은 구현 설계이며 이번 런처 수정에서 보조 모드 JAR을 만든 것은 아닙니다.

6. 메뉴 버튼을 실제 기능으로 연결
단순 공지나 도움말은 HTML만으로 구성할 수 있습니다.
상점 구매, 보상 지급, 순간이동, 포켓몬 정보는 서버 쪽 기능 연결이 필요합니다.
페이지에서 postToGame 이벤트를 보내고 서버 모드가 권한·잔액·조건을 확인해 처리하는 구조가 적합합니다.
페이지 JavaScript만으로 아이템을 지급하거나 포켓몬 데이터를 신뢰해서 처리하지 않습니다.

7. 런처 업데이트와의 관계
포켓메이트 업데이트 목록에는 클라이언트용 WebGUI, Fabric API, 보조 모드 JAR을 넣습니다.
server.json은 서버에서 관리합니다. 자동 생성된 tokenSecretBase64 등 서버 비밀값을
클라이언트 배포용 files/config에 복사하거나 ZIP에 포함하지 마세요.
서버 내장 메뉴 HTML 변경은 서버에 적용하고 /webgui reload로 전달하므로
메뉴 문구나 디자인 변경마다 런처의 모드 JAR을 다시 배포할 필요는 없습니다.
아직 실제 서버 주소와 모드 팩이 없으므로 이 연동을 실제 서버에서 검증하지는 않았습니다.
